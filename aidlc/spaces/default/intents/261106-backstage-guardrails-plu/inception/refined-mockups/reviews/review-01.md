### Suggestions

- Announcing the character counter on every keystroke is noisy. Announce it only at thresholds (for example 50 and 0 left).
- Show the change's failure message on Screen C for failed changes, so Retry is an informed decision.

### Summary

The three screens cover most stories, the Q1-Q6 answers are reflected, and the main rules (required reason, no self-approval, refused entries) are shown. The artifacts are not yet ready for engineering. The demo-user switch has no design, the read-only role is an untraced requirement, Screens A and C lack states, and the accessibility checklist misses several WCAG 2.1 AA areas.
